# Inbox

Drop a scanned PDF or photos of a piece here and it is read into the Listen
library automatically, usually within five minutes.

- **Name the file for the piece:** `Gavotte - Gossec.pdf` becomes the title
  "Gavotte" by "Gossec". Without ` - `, the whole name is the title.
- **Several photos of one piece:** put them in a folder named for the piece,
  with the photos named in page order (`1.jpg`, `2.jpg`, …).
- Lines the page labels as exercises ("Bonus exercise", "Warm-up", …) are left
  out. To keep every line, end the name with `[all]`: `Etude 3 [all].pdf`.
- The file is removed from the inbox once it has been read.

This repository is public: only add music you are free to share. A removed file
stays in the repository's history.
